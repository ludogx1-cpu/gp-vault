🤖 Use the tool from your AI assistant

The Golden Paw Animation Creation Tool is also an AI plugin. Ask Claude, in plain English, to turn a video into a sprite sheet, and it runs the tool for you, on your own computer.

Just ask

  • "Turn shiba-run.mp4 into a sprite sheet at 12 fps and remove the green screen."
  • "Make a transparent GIF of seconds 2 to 4 of this clip, half size."
  • "Cut this sprite sheet into separate frames using its JSON."
  • "Remove the background from these three character images." (Pro)

You get the same results as the website: a packed sprite sheet, a TexturePacker JSON atlas for Phaser, PixiJS, Godot and other engines, an animated GIF and individual frames, with trimming, scaling and ping-pong loops. Claude shows you a preview of the result.

Private by design

The plugin runs on your computer, just like the website does in your browser. Your videos are never uploaded anywhere.

Install in Claude Code

You need Node.js 20 or newer. In Claude Code, type:

/plugin marketplace add ludogx1-cpu/a-new-space
/plugin install golden-paw-animate@golden-paw

The first start takes a few seconds while it sets itself up. After that, just ask.

Install in Claude Desktop and other MCP apps

The plugin speaks the open Model Context Protocol (MCP), so it works with any app that supports MCP servers. In Claude Desktop, open Settings → Developer → Edit Config, add the following to claude_desktop_config.json, then restart the app:

{
  "mcpServers": {
    "golden-paw-animate": {
      "command": "npx",
      "args": ["-y", "golden-paw-animate-mcp"]
    }
  }
}

Free and Pro

  • Free: sprite sheets, JSON atlases, GIFs, frame export, trimming, and green-screen or solid-colour background removal.
  • Pro: AI background removal from any background, no green screen needed. One Pro purchase (£11.99, no subscription) unlocks it on the website, the desktop app and the AI plugin. Tell Claude "activate Pro with my key" and paste the key from your purchase email.

The first time you use AI background removal, the plugin downloads the AI engine and model (about 70 MB, once). After that it works offline.
