How to import a sprite sheet into Godot 4

Godot can slice a grid sprite sheet into an animation in a couple of clicks. Sheets from this tool are an even grid with no gaps between cells, which is exactly what Godot's importer expects.

Before you start

  • Export a sprite sheet from the converter. Note the number of columns and rows shown under the preview (they're also in the .json file).
  • PNG and WebP both work in Godot 4. Choose PNG if you're unsure.
  • Leave Pad sheet to power-of-two off. The padding adds empty space that would throw off Godot's grid.
  • Drag the image into your project's FileSystem dock.

Method 1: AnimatedSprite2D (easiest)

  1. Add an AnimatedSprite2D node to your scene.
  2. In the Inspector, set Sprite Frames to New SpriteFrames, then click it to open the SpriteFrames panel at the bottom of the editor.
  3. Rename the default animation, for example to run.
  4. Click the Add frames from sprite sheet button (the grid icon) and choose your image.
  5. Set Horizontal to your number of columns and Vertical to your number of rows.
  6. Click Select/Clear All Frames. If the last row isn't full, click to deselect the empty cells. Then click Add frames.
  7. Set the animation speed (FPS) to match the FPS you exported with, and turn Loop on or off.

Play it from a script:

func _ready():
    $AnimatedSprite2D.play("run")

Method 2: Sprite2D with hframes and vframes

Useful if you drive animations with an AnimationPlayer, for example to sync frames with hitboxes or sounds.

  1. Add a Sprite2D and drag your sheet onto its Texture.
  2. Under Animation, set Hframes to your columns and Vframes to your rows.
  3. The Frame property now picks a cell, counting from 0 left to right, then down. Key it in an AnimationPlayer, or step it in code:
var t := 0.0
const FPS := 12.0
const FRAME_COUNT := 24  # frames in your sheet

func _process(delta):
    t += delta
    $Sprite2D.frame = int(t * FPS) % FRAME_COUNT

Pixel art looks blurry?

Godot smooths textures by default. For pixel art, go to Project Settings → Rendering → Textures and set Default Texture Filter to Nearest, or set Texture → Filter to Nearest on the node itself. Also export with Crisp edges and no edge feathering.

Trimmed sheets still line up

Trim transparent padding crops every frame to the same shared box, so the cells stay an even grid and Godot slices them correctly. The animation won't jitter.
